Make sure to have Maven and NPM for vite and React installed. It's pretty easy to find the commandline arguments for those online. 

Once those are installed, you will need to terminals open to run the backend and frontend. You must run the backend command first and let it finish its process. 

Backend commands for terminal1:

cd cs4050e-deliv2
mvn -q clean compile
mvn exec:java -Dexec.mainClass=cs4050e.deliv2.App

Frontend commands for terminal2:

cd frontend
npm run dev
