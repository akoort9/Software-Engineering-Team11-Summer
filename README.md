You can run the following while in the frontend directory to download all dependencies for the project in order to run it.
```
npm install
``` 

Once they are installed, you will need to terminals open to run the backend and frontend. You must run the backend command first and let it finish its process. 

Backend commands for terminal1:

cd backend/
./run.sh

Frontend commands for terminal2:

cd frontend
npm run dev
